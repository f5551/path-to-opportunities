# قواعد أمان بيئة العمل وضوابط التطوير — PATH TO OPPORTUNITIES

تُطبق هذه القواعد بصورة دائمة وملزمة (`trigger: always_on`) على كافة العمليات والأدوات داخل هذا المشروع:

## 1. ثنائية اللغة والاتجاه (RTL / LTR)
- **العربية لغة افتراضية:** اللغة العربية (`dir="rtl"`) هي اللغة الأساسية الافتراضية للتطبيق، مع دعم فوري وكامل للغة الإنجليزية (`dir="ltr"`).
- **التصميم المتكافئ:** يجب استخدام الخصائص المنطقية في CSS (`margin-inline`, `padding-block`, `inset-inline-start`, `inset-inline-end`, `text-align: start`) لضمان محاذاة صحيحة تلقائياً في كلا الاتجاهين.
- **انعكاس الأيقونات الاتجاهية:** يجب أن تنعكس الأيقونات المرتبطة بمسار الحركة والتنقل (كالأسهم ومؤشرات التالي والسابق) في وضع RTL، مع إبقاء الأيقونات العامة (كالبحث والساعة والتقويم والمفضلة) دون انعكاس.

## 2. التوافق مع الهواتف وشاشة 360px
- **معيار 360px أولاً:** يجب أن تعمل جميع واجهات وصفحات وبطاقات المنصة بسلاسة ووضوح تامين على الشاشات الصغيرة بدءاً من عرض **360px**.
- **انعدام التمرير الأفقي:** يُحظر تماماً حدوث أي تمرير أفقي غير مقصود (`overflow-x`) عبر كافة المقاسات (360px, 390px, 768px, 1024px, 1440px).
- **أحجام اللمس وإمكانية الوصول:** لا يقل أي عنصر تفاعلي (زر، رابط، حقل اختيار) عن **44×44px** وفق معيار WCAG 2.2.

## 3. حظر الـ CDN والاستضافة الذاتية للموارد
- **منع استخدام CDNs:** يُحظر تماماً استدعاء أو ربط أي مكتبات أو خطوط أو أنماط أو أيقونات من شبكات خارجية (مثل Google Fonts, cdnjs, unpkg, jsdelivr).
- **الاستضافة المحلية:** تُستضاف كافة الخطوط (Noto Sans Arabic, Inter) والأصول محلياً داخل مجلدات المشروع (`public/fonts/`, `public/assets/`).

## 4. حماية بنية المشروع ومنع الحذف غير المصرح به
- **منع الحذف دون إذن:** يُحظر تماماً حذف أو إعادة تسمية أي ملف أو وحدة أو أصل برمجي في المستودع دون موافقة مسبقة وصريحة من المستخدم.
- **منع إعادة الهيكلة التلقائية:** يُمنع تغيير البنية المعمارية للمجلدات أو تبديل أدوات البناء دون تكليف صريح.
- **الحفاظ على الأكواد والوظائف السليمة:** يُمنع تعديل أو إعادة كتابة أي وظائف برمجية سليمة ومختبرة دون وجود خلل مثبت يستدعي الإصلاح.

## 5. حماية الأسرار والأمان السيبراني
- **منع قراءة الأسرار:** يُحظر نهائياً فتح أو قراءة أو استعراض أو تسجيل محتويات أي ملفات أسرار أو متغيرات بيئة أو بيانات اعتماد ومفاتيح وصول (مثل `.env*`, `*secret*`, `*key*`, `*token*`, ملفات المفاتيح الخاصة).
- **التحصين ضد الثغرات:** تمرير كافة البيانات الديناميكية المعروضة عبر دوال التعقيم المخصصة ضد هجمات XSS (`escHtml`, `escAttr`) وقصر الروابط على بروتوكول `https://` المعقم (`sanitizeUrl`).

## 6. مراجعة الخطط والتعديل المعتمد
- **الخطة أولاً:** تقديم خطة عمل واضحة وموجزة توضح الملفات المستهدفة بالتعديل أو الإنشاء قبل إجراء أي تغييرات جوهرية.
- **انتظار الموافقة:** التوقف لانتظار موافقة واعتماد المستخدم الصريحة قبل الشروع في التعديل، والالتزام فقط بالتعديلات المصرح بها.
