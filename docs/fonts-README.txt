Place the following font files in this directory:

1. NotoSansArabic-VariableFont_wdth,wght.woff2
   Download from: https://fonts.google.com/noto/specimen/Noto+Sans+Arabic
   (Download the variable font zip and extract the WOFF2 file)

2. InterVariable.woff2
   Download from: https://github.com/rsms/inter/releases/latest
   (Or from https://rsms.me/inter/)

The application will work without these fonts, falling back to system fonts.
Both are self-hosted to avoid CDN dependencies and ensure offline capability.
